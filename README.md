# Orbit Chat Releases

Official downloads for **Orbit Chat**, an independent Windows chat application.

## Download

### Recommended: Online Installer

[Download the Orbit Chat Online Installer](https://github.com/redoszeryk0-sys/OrbitChat-releases/releases/download/Online_installer/Orbit-Chat-Online-Installer.exe)

Run the installer to choose a version and installation location. It downloads the selected release and checks its SHA-256 digest when one is provided by GitHub. When setup finishes, choose **Open & exit** to launch Orbit Chat or **Exit** to close the installer.

### Portable version: 1.2.1

[Download Orbit Chat 1.2.1 for Windows x64](https://github.com/redoszeryk0-sys/OrbitChat-releases/releases/download/1.2.1/Orbit-Chat-1.2.1-win-x64.zip)

Extract the ZIP to a folder and run `Orbit Chat.exe`.

## Open Source

Orbit Chat is an open-source project. The source code is available in this repository. Please see [LICENSE](LICENSE) for the applicable terms.

## Requirements

- Windows 10 or Windows 11, 64-bit
- Internet access to use the online installer. The portable ZIP can be downloaded directly.

Orbit Chat and its installer are currently unsigned, so Windows SmartScreen may display a warning.

## Development

Orbit Chat was made with substantial assistance from AI tools—sometimes called **“vibe coding.”** AI helped generate and modify parts of the app; the project is directed and maintained by its creator.

## Release verification

Portable releases use the filename format `Orbit-Chat-<version>-win-x64.zip`. The online installer selects the highest semantic version that has a matching Windows ZIP. GitHub displays an asset’s SHA-256 digest on its release page when available.

Installing, updating, or uninstalling Orbit Chat preserves your account data and settings.
