# Orbit Chat Releases

Official Windows downloads for **Orbit Chat**, an independent desktop chat application.

## Download Orbit Chat

**Recommended — Online Installer**

[Download Orbit-Chat-Online-Installer.exe](https://github.com/redoszeryk0-sys/OrbitChat-releases/releases/download/Online_installer/Orbit-Chat-Online-Installer.exe)

Run the installer, choose an available version and install location, then follow the setup steps. It fetches the matching Windows x64 release ZIP from this repository and checks the SHA-256 digest when GitHub provides one. After setup, choose **Open & exit** to launch Orbit Chat or **Exit** to close the installer.

**Portable ZIP — Orbit Chat 1.2.1**

[Download Orbit-Chat-1.2.1-win-x64.zip](https://github.com/redoszeryk0-sys/OrbitChat-releases/releases/download/1.2.1/Orbit-Chat-1.2.1-win-x64.zip)

Extract the ZIP to a folder you control and run `Orbit Chat.exe`. The portable ZIP does not include the installer's uninstaller helper.

For additional versions and release notes, visit the [Releases page](https://github.com/redoszeryk0-sys/OrbitChat-releases/releases).

## System requirements

- Windows 10 or Windows 11, 64-bit
- Internet access is required by the online installer to retrieve releases. The portable ZIP can be downloaded directly instead.

Orbit Chat and its installer are currently unsigned. Windows SmartScreen may display a warning when opening them.

## Release files and verification

Portable releases are named `Orbit-Chat-<version>-win-x64.zip` and contain the Windows x64 app. The online installer uses semantic version tags and selects the highest version that has a matching portable ZIP. GitHub displays each uploaded asset's SHA-256 digest on its release page when available.

Orbit Chat account data and settings are stored separately from the application files. The installer preserves them during updates and uninstallations.
